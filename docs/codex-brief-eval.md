 - mode déterministe par défaut: rejoue chaque cas via la fonction de route existante (en process), vérifie propriétés + invariants globaux (monotonie des lignées sur le registre, budget jamais dépassé, famille différente, jamais hors --available).  - --available <liste|fichier|live> (live = list_copilot_models.py), --registry, --refresh (lance scripts/refresh.sh ou list+sync avant), --cases, --json, --report eval/report.md (par défaut l'écrit), --filter role/id.
 - --judge: client juge abstrait (interface judge(case, decision)->{score 0..1, justification}); FakeJudge déterministe (basé sur l'écart tier attendu/choisi, pour CI) et CopilotJudge (--copilot --judge-model <id>: subprocess `copilot --model <id> -p "<prompt>"`, demande JSON strict, parsing robuste, timeout, erreurs comptées sans planter). Calcule score moyen global/rôle/tier, taux de succès, seuil --threshold (défaut 0.85), code non nul sous le seuil.
 - Garde anti-dérive: si liste live dispo, échoue clairement si un modèle de l'org n'a pas de tier dans le registre, ou un modèle du registre absent de l'org (« lancer refresh »); sans liste live → statut SAUTÉ, pas échec.
